# 20 Strong Probability Lab

A browser-only probability and decision-support tool for the core dice system in **20 Strong**.

## Current scope

- Exact damage distribution for any mix of yellow, green, blue, purple, and red dice.
- Kill probability for a target damage value.
- Expected damage.
- Probability of rolling at least one crit.
- Unit tests for the core probability engine.
- GitHub Pages deployment workflow.

## Planned

- Strategy reroll modeling based on the exact core rules.
- Marginal value of adding one die of each color.
- Minimum reliable dice pool for 80% / 90% / 95% success thresholds.
- Recovery-aware pool cost and Pareto-frontier optimization.

## Development

```bash
npm install
npm run dev
npm test
npm run build
```

This is an unofficial fan-made probability tool. It does not include card art or module content.
